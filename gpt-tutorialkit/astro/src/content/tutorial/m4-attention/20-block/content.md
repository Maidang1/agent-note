## 为什么要这样包一层

一个 Block = 交流（多头注意力）+ 计算（前馈）。GPT 就是把 Block 叠很多层。但简单叠起来，网络一深就很难训练。原版用了两个关键技巧：

<strong>1. 残差连接</strong> `x = x + 子层(x)`

子层不直接替换 x，而是算出一个「修改量」加回去。好处：

- 梯度可以沿着 `+` 号直接流回前面的层，深层网络不再因为梯度一层层衰减而学不动。
- 刚初始化时子层输出很小，整个 Block 接近「什么都不做」，网络从一个稳定的起点开始，慢慢学到有用的修改。

可以想象一条贯穿所有层的「主干道」（residual stream），每个子层从路上读信息、算完再把结果加回路上。

<strong>2. LayerNorm（预归一化）</strong> `子层(ln(x))`

LayerNorm 把<strong>每个位置</strong>的向量归一化成均值 0、标准差 1，再乘上可学习的缩放、加上偏移。这样子层收到的输入尺度稳定，不会因为前面层的输出越加越大而失控。原版 Transformer 论文把 LayerNorm 放在残差相加<strong>之后</strong>；现在普遍放在子层<strong>之前</strong>（pre-norm），训练更稳。gpt.py 用的就是 pre-norm。

<strong>先猜一猜</strong>：如果把 `x = x + self.sa(self.ln1(x))` 写成 `x = self.sa(self.ln1(x))`，输出形状会变吗？会出什么问题？

<details><summary>想好了再点开</summary>

形状<strong>不变</strong>，代码能跑。但残差没了：输入的信息只能经过注意力层才能传到后面，深层网络会难以训练。第三条检查就是专门抓这个错误的：把两个子层的输出清零，有残差的 Block 应该原样传出输入。

</details>
