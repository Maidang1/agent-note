# 一个 agent 在做什么

这个教程讲 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（下文简称 dsh）是怎么搭起来的。dsh 是一个 **agent 框架**。所以先回答一个问题：agent 是什么？

## 模型只会接着写

大模型做的事情其实很单一：读进一段文字，接着往下写一段。它不能自己算数，不能读文件，也不能上网。

**agent** 是包在模型外面的一段程序，让模型能“做事”：

1. 把对话和“你可以用哪些工具”一起发给模型；
2. 模型可能直接回答，也可能说“请帮我调用 `add`，参数是 1 和 2”；
3. 如果是后者，agent 就去真的执行这个工具，把结果再发给模型；
4. 重复第 2、3 步，直到模型给出最终回答。

用户说一句话，到 agent 给出最终回答，叫一个**轮次**（turn）。轮次里每问一次模型，叫一个**步骤**（step）。

## 这一课的代码

左边的 `main.ts` 已经装好了一个能运行的 agent。现在只需要知道三件事：

- `createHarness()` 搭好一个 agent，用的是 npm 上发布的真实 dsh 代码；
- 模型是**假的**：它按 `rules` 里写好的规则回答，不联网，也不需要 API key，所以每次运行结果都一样；
- `harness.send('你好')` 发一条用户消息，等这一轮结束。

代码的写法下一课再细看。

## 看流程图

右下方的**流程图**画的就是这个 agent。每个方块是一个**插件**：dsh 把 agent 的每个部分都做成了插件，会话记录、提示词、工具、模型、主循环都是。现在不用记住它们的名字，**点一下方块**就能看到一句说明，比如：

- `agent-loop`：主循环，就是上面那四步；
- `llm-scripted`：这个教程的假模型；
- `calculator`：能做加法的工具。

流程图上方会依次显示这一轮的每一步。点“回放”，或者用 ◀ ▶ 一步一步看。每一步下面有一句大白话说明；点“步骤”可以打开完整的步骤列表。

现在发的是“你好”，模型直接回答，这一轮只有一个步骤：

| 步骤 | 发生了什么 |
|---|---|
| 用户输入「你好」 | 消息交给 `agent-loop` |
| 写入会话日志 | 记下收到的消息和“一轮开始” |
| `system-prompt/assemble` | 组装系统提示词：告诉模型它是谁、能用哪些工具 |
| `agent/pre-step` | 问模型之前的检查点，插件可以在这里拦下这一步 |
| 写入会话日志 | 先把要发给模型的内容记下来 |
| 请求 #1 | 发给模型 |
| 响应 #1 | 模型回答“你好！我会做加法，问我 1+2 试试。” |
| 写入会话日志 | 记下回答，一轮结束 |

“写入会话日志”出现了三次。dsh 把发生的每件事都按顺序记在会话日志里，发给模型的内容也要先记下来再发。后面有一整章讲为什么要这样做。

## 动手

把最后的“你好”换成“1+2”：

```ts
await harness.send('1+2')
```

保存后程序自动重新运行。这次模型没有直接回答，这一轮变成了两个步骤：

1. `请求 #1` 发给模型，`响应 #1` 是“调用 add({"a":1,"b":2})”：模型请求调用工具；
2. 接着四步 `tools/…` 由工具运行时 `tools` 完成，其中 `tools/execute · add` 指向 `calculator`，真正算出了 3；
3. 结果 3 写进日志，再组装一次提示词，发出 `请求 #2`；
4. `响应 #2` 是“1+2 等于 3”，模型不再调用工具，这一轮结束。

这就是开头说的四步，在真实的代码里跑了一遍。
